# MOU-8. Leave IBA annotations to GO Central

## Decision

A group does not submit its own IBA annotations. GO Central adds the current IBA set to each group's annotations at every release, and removes any IBAs a group submitted.

## Context

Phylogenetic annotations come from PAINT curation at GO Central, so one current set replaces whatever a group's file contains.
