# AE-12. An extension needs the same evidence as the annotation. Do not expect or invent extensions on propagated rows.

## Decision

An extension needs the same evidence as the annotation. Do not expect or invent extensions on propagated rows.

## Context

The extension is part of the claim, so the cited reference must support it. ISS, ISO, IBA and IEA pipelines do not carry extensions: "Currently annotation extensions are not being propagated" ([Drive: GP2term and extensions (2021)](https://drive.google.com/open?id=128U6g91Iv2ej9pcgTSGOowbhjp4GwGXmE4gDTiue1Cc)). MGI's rat-to-mouse ISO filters do not import them either ([Drive: MGI ISO rat filters](https://drive.google.com/open?id=1lx65V8ikyofnkDdwojm6fhHZ801ET1Z9)). A gene-product filler in a transferred extension would name a gene in the source species, which is wrong for the target.

**Rule detail.** A manually transferred extension needs the target-species filler, such as the orthologous substrate, and a curator's judgement that the orthologous relationship holds.
