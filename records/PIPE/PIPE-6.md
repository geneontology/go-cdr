# PIPE-6. Documentation: keep the GO_REF metadata complete and current

## Decision

Every pipeline has a GO_REF with complete metadata. For a machine-learning pipeline it links the exact training data (for example on Hugging Face); for a mapping or rule pipeline it links the mappings or rules and documents how they are updated.

## Context

The GO_REF is where users and curators find out how an annotation was made.
