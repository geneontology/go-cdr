# PIPE-1. Responsivity: respond to curator issues in a timely way

## Decision

A pipeline's output changes in a timely way in response to issues raised on the go-annotation tracker.

## Context

Curator feedback is how GO improves the precision and recall of automated annotation. The responsibility is shared: GO Central ensures the automatically assigned contact for a pipeline is correct. Importance: high.

## Application

*Examples.* InterPro2GO removing mappings in response to tracker comments; PAINT updating ancestral node annotations or adding IKR NOTs.

*Counter-examples.* A pipeline produced by a machine-learning group for a paper and not kept up to date; a deep-learning pipeline whose weights cannot be corrected for one case.
