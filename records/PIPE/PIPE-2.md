# PIPE-2. Currency: rebuild and re-run the pipeline regularly

## Decision

The model behind a pipeline is retrained or rebuilt regularly; a rule or mapping pipeline is actively curated; and the pipeline itself is re-run.

## Context

The ontology, the sequence databases and the experimental record all change. The IEA date-stamp rule is an arbitrary, imperfect proxy for currency.

## Application

*Examples.* PAINT updates with PANTHER releases; ARBA retraining.

*Counter-example.* A deep-learning pipeline that is never retrained.
