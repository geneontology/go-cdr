# PIPE-8. Uniqueness: complement the existing pipelines

## Decision

A pipeline adds annotations that complement the existing pipelines. Reasonable redundancy is expected and may vary by taxon.

## Context

Each pipeline costs curator attention to maintain; one that only repeats others adds cost without coverage.
