# PIPE-7. Benchmarking: evaluate against a consortium benchmark before release

## Decision

A pipeline is benchmarked against a benchmark the consortium has agreed. Consortium members can also run their own evaluations (spot checks, species-specific checks) before release.

## Context

Few pipelines meet this yet because GO lacks shared benchmarks; ARBA is one that does. Spot-checked pipelines are the next best. An AI-as-judge approach is one possible way to scale evaluation.
