# RS-12. IEP supports "response to" and other BP terms only for normal expression, and usually only as a non-core role

## Decision

**Statement.** IEP may support BP terms only (GORULE:0000006), and only from normal expression patterns. Overexpression and ectopic expression are IDA or IMP evidence. Before accepting an IEP row, ask whether the gene product is an agent of the process or a bystander whose abundance tracks it. In review, the default action for a sound induction observation that is not the gene's job is `KEEP_AS_NON_CORE`. Use `MARK_AS_OVER_ANNOTATED` for stimulus clouds (one enzyme, many unrelated "response to X" terms from separate exposure papers), for developmental time-courses read as tissue-building roles, and for one-screen batches. Use `REMOVE` only for a categorical mismatch. Do not remove an IEP row merely because the code is weak.

## Context

[wiki: Inferred from Expression Pattern (IEP)](https://wiki.geneontology.org/index.php/Inferred_from_Expression_Pattern_%28IEP%29) restricts the code to BP and to normal expression, and advises caution and high-level terms. In this repository's reviews, 22.5% of IEP rows were accepted and 55.6% kept as non-core. The characteristic IEP row is true but peripheral ([IEP](https://ai4curation.io/ai-gene-review/pages/projects/IEP.html)). Both figures come from AI reviews primed to look for over-annotation, so they describe one reviewer population, not an independent audit (same page).

## Application

**Worked example.** Rat Gstt1 carries GO:0009410 response to xenobiotic stimulus plus salicylic acid, selenium ion and vitamin E response terms, each from a separate induction paper. All describe one broad-specificity transferase. Keep the xenobiotic term as non-core. Mark the sibling stimulus terms as over-annotated ([IEP](https://ai4curation.io/ai-gene-review/pages/projects/IEP.html), pattern 1).
